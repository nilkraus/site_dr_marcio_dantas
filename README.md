Landing Page - Advogado Márcio Dantas

Landing page profissional desenvolvida para o advogado **Márcio Dantas**, com foco em **captação de clientes, credibilidade e conversão**, apresentando seus serviços jurídicos de forma clara, objetiva e estratégica.

Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de criar uma presença digital sólida para um profissional da área jurídica, transmitindo:

- Autoridade
- Confiança
- Clareza na comunicação
- Facilidade de contato

A página foi pensada para transformar visitantes em potenciais clientes, utilizando princípios de design estratégico e experiência do usuário.

 Funcionalidades

Apresentação profissional do advogado  
Estrutura de conteúdo focada em conversão  
Seções organizadas (Sobre, Serviços, Contato)  
Botão de contato direto (WhatsApp ou similar)  
Layout responsivo para diferentes dispositivos  

Objetivo

Desenvolver uma landing page capaz de:

- Atrair novos clientes
- Comunicar serviços jurídicos com clareza
- Facilitar o contato direto
- Posicionar o profissional como autoridade na área
 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript 

 Destaques do Projeto

- Estrutura semântica para melhor organização e SEO  
- Design limpo e profissional alinhado ao público jurídico  
- Interface intuitiva e de fácil navegação  
- Foco em experiência do usuário (UX) e conversão
